
# 🌟 **Evershop Manual Testing Project** 🌟

Welcome to the **Evershop Manual Testing Project** repository! This repo contains all the documentation and reports related to the manual testing conducted on the [Evershop](https://demo.evershop.io/) website.

## 🚀 **Project Overview** 
The primary objective of this project was to perform **manual testing** on the [Evershop](https://demo.evershop.io/) website, ensuring optimal functionality, usability, and bug-free performance. The testing phases included UI testing, API testing, feedback, and issue reporting.

---

## 📝 **Testing Phases** 

### 1. **UI Testing** 🎨
- **What was tested**: Website responsiveness, user interface consistency, and design.
- **Tools Used**: Manual testing, browser testing.
- **Outcome**: Identified UI issues and logged them for resolution.

### 2. **Test Execution** 🏃‍♂️
- **What was tested**: Executed predefined test cases to validate site functionality.
- **Outcome**: Successful execution of tests and identification of potential bugs.

### 3. **Issue Reporting** 🐞
- **What was reported**: Detailed list of bugs and issues encountered.
- **Tools Used**: GitHub Issues, Test Management tools.
- **Outcome**: Comprehensive issue report backlog to track all open issues.

### 4. **Test Case Creation** 📑
- **What was created**: Manually crafted test cases to ensure each feature was tested thoroughly.
- **Outcome**: A structured list of test cases used for validation.

### 5. **API Testing (Postman)** 🔌
- **What was tested**: API endpoints using **Postman**.
- **Outcome**: Verified that the API endpoints returned correct responses and adhered to expected functionality.

### 6. **Feedback** 💬
- **What was gathered**: Insights and suggestions for improvements from testing.
- **Outcome**: Actionable feedback for developers and team members.

---

## 📂 **Files in this Repository** 

This repository contains the following files:
- **Test Cases**: All manually created test cases.
- **Issue Reports**: A comprehensive list of issues found during testing.
- **Test Execution Reports**: Documentation of test execution results.
- **Postman API Testing Reports**: Documentation of Postman-based API testing.
- **Feedback**: Collected feedback from the testing process.
